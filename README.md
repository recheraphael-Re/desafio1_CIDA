# Desafio 1 CIDA

Raphael Gouvêa Reche — RA 26164063.

Solução em Python dos itens a a f do enunciado, usando as amostras 16 a 31.

## Execução

Abra o terminal nesta pasta e execute:

```powershell
python -m pip install -r requirements.txt
python desafio1.py
```

Consulte `desafio1-CIDA.docx` para a documentação e `desafio1-CIDA.md` para a versão editável em Markdown. Os gráficos e as respostas são gravados em `resultados`, junto ao programa. Não é necessário abrir janelas gráficas.

Os quartis de temperatura usam interpolação linear. A comparação global de rotação apresenta caixas e medianas, pois o enunciado não fornece os extremos globais. A cobertura aproximada de 68% depende da hipótese de normalidade.
